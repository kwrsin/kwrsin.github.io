Light Weight Simple Memo

A lightweight memo pad for Markdown and HTML. Works offline as an installable app (PWA).

Basics

  • Type in the editor. Every change is saved automatically in your browser (local storage on this device). Nothing is sent to a server.
  • The switch in the header toggles between Preview (on) and Edit (off). The app opens the last memo you used, in preview.
  • Memos can be written in Markdown or HTML. A memo that starts with an HTML tag is treated as HTML. In preview, scripts, styles, and event attributes are removed for safety.
  • Links in the preview open in a new tab.
  • Drag and drop Markdown, HTML, or text files onto the window to open them as new memos.
  • On narrow screens the header buttons do not wrap; swipe the header sideways to reach all of them.
  • On a phone in portrait orientation the header (title and buttons) floats at the bottom of the screen. It hides while you scroll down, comes back when you scroll up or switch memos, and hides while the keyboard is open. Tap the ⌄ button at the top right to close the keyboard.
  • Title: the first line that has visible text (Markdown or HTML marks are stripped). An imported memo uses its file name instead. The title is also shown in the browser tab. A memo with no visible text is not saved.
  • The color button changes the memo's background color; the circular arrow resets it.
  • Each memo has an internal ID, used for editing and deleting.
  • The header hides while you scroll down and returns when you scroll up.

Find and replace

  • Type a keyword and press Find (or Enter) to find the next match. It wraps around at the end of the memo. Click Find again for the next one.
  • The match is selected (highlighted) in the editor, and the app switches to edit mode if needed. The dialog stays open at the top and the editor stays usable. Press F9 to jump back to the Keyword box.
  • Replace replaces the selected match with the Replacement text and jumps to the next one. If nothing is selected, it just finds the next match.
  • All: Replace changes every match at once.
  • Case sensitive: when ticked, upper and lower case letters are treated as different. This applies to finding and replacing.
  • Esc or the ✕ button closes the dialog.

Memo list

  • Memos are sorted by most recently used. The Filter box narrows the list as you type.
  • Ctrl+N (or ↓) next item, Ctrl+P (or ↑) previous item.
  • Space or Enter opens the selected memo and closes the list. While the Filter box has text, Space types a space; use Enter.
  • Delete deletes the selected memo after confirmation. The × button on a row does the same; Delete all removes every memo.
  • Esc or the ✕ button closes the list. The same applies to Find.
