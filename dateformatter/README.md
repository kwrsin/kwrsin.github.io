# Date Formatter

An intuitive web-based date and time formatting tool with interactive calendar controls and versatile format presets.

[English](#english) | [日本語](#日本語)

---

## English

### Credits & Authorship

This application is a collaborative creation developed jointly by **kwrsin** and **Antigravity**.

- **kwrsin**: Project Owner, System Architecture, UI/UX Design & Direction
- **Antigravity**: AI Pair Programmer & Co-developer (Google DeepMind)

### Key Features

- **Interactive Calendar**: Quick navigation across months, instant jump to "Today", and visual day picker.
- **Time Picker**: Second-level precision with a quick "Current Time" button.
- **Flexible Token Formatting**: Full support for standard date/time tokens (`YYYY`, `YY`, `MMMM`, `MMM`, `MM`, `DD`, `dddd`, `HH`, `hh`, `mm`, `ss`, `A`/`a`, literal brackets `[...]`).
- **One-Click Clipboard Copy**: Instantly copy formatted strings with visual feedback.
- **Preset Chips**: Fast switching between commonly used formats (ISO 8601, Japanese format, compact, slash, etc.).
- **Live Locale Detection**: Displays detected browser locale and formats accordingly.

## 日本語

### クレジット / 開発体制

本アプリケーションは、**kwrsin** と **Antigravity** の共同作業によって開発されました。

- **kwrsin**: プロジェクトオーナー、設計・UI/UX仕様策定、開発ディレクション
- **Antigravity**: AIペアプログラマー、実装支援・コード生成（Google DeepMind）

### 主な機能

- **インタラクティブなカレンダー**: 日付の直感的な選択、月移動、当日へのクイックジャンプ
- **時刻の選択**: 秒単位での入力および「Current Time」ボタンによる現在時刻セット
- **柔軟なフォーマット指定**: `YYYY`, `MM`, `DD`, `HH`, `mm`, `ss`, `dddd` など豊富なトークンに対応
- **ワンクリックコピー**: フォーマットされた文字列をクリップボードに素早くコピー
- **プリセット機能**: よく使われるフォーマット（ISO 8601、スラッシュ区切り、日本語表記など）をワンタップで切り替え
- **ブラウザロケール自動認識**: 現在のロケールバッジ表示と適切な言語表現
