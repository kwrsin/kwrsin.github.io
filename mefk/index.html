📘 MIND ELIXIR for Kwrsin — HELP

🗂 Basics

  • Start from the central node (e.g., Project) to build your mind map.
  • Select a node to edit its details in the right sidebar.
  • All data is saved automatically in localStorage.
  • Reserve status is shown in the bottom-right toolbar:
    • ✅ reserved (green): already reserved
    • ❌ unreserved (red): not reserved yet

📝 Note Editing (Sidebar)

  • Select a node to open the sidebar.
  • Edit Tab: Write notes in Markdown.
  • Preview Tab: Preview formatted Markdown.
  • Update Button: Save note to the node (✔ Updated will show).

🌐 URL Settings

  • Image URL: Display an image on the node (size auto-fetched).
  • Site URL: Add a hyperlink to the node.
  • ⚠️ Only http:// and https:// are valid.

🎨 Node Colors

  • Use the sidebar’s color options to set background and text colors.
  • Click reset to restore default.

📂 Export / Import

  • To Image: Save as PNG
  • To Dir: Save as folder (ZIP) — starts from the selected node
  • Export (JSON): Save as JSON
  • Import (JSON): Load from JSON (drag & drop supported)

☰ Node Manipulator

  • Node manipulation
  • Please select a node before editing the node.

💡 Tips

  • If a node name includes an extension (e.g., .txt, .md), it will be exported as a file.
  • Sidebar state (open/closed) is preserved per node.
  • Data persists in localStorage, so it remains even after closing the browser.
